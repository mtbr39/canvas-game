canvas-game

ゲームを作るためのライブラリ Reson と、その上で動くゲームたち。

どのゲームも同じ bundle.js（同じエンジン）を読み込み、ページにある canvas の id で、どのゲームを始めるかを切り替えています。 描画・衝突判定・入力・カメラ・ゲームループは共通で、ゲームごとに違うのは載せる部品だけです。

  • 群れシミュレーション
    同じ種どうしは向きをそろえて集まり、自分より大きい別の種からは逃げる。大きさや速さの違う5種類の生き物が泳ぐ。
  • 町を歩く住人
    道をグラフとして作り、住人が店や宿屋へ経路探索で向かう。クリックで道を描き足せる。
  • アイテムを拾う冒険
    段差のある地形をキャラクターが歩き、落ちているアイテムを拾う。バッグとショップの画面つき。
  • MOBA 風の対戦
    チャンピオンを右クリック（スマホはタップ）で動かし、Q でマウスの方向に弾を撃つ。ミニオンと戦う。
    他のプレイヤーとの同期には Socket.IO のサーバー（backend/）が必要
  • 会話する住人
    住人がまわりの様子やほかの人の発言を見て、LLM で話す。
    話すには LLM の APIキー（config-env.js）が必要
  • 石を狙って飛ばす
    石を選んで目的地をクリックすると軌道の予測が出て、もう一度押すと回転のかかった石が飛んでいく。
